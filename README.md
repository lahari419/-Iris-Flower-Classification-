Iris Flower Classification Using Machine Learning
Project Description
This project predicts the species of an Iris flower based on its measurements using Machine Learning.

Technologies Used
Python
Machine Learning
Scikit-learn
Streamlit
Dataset
Iris Dataset (Scikit-learn)
150 samples
4 input features
3 flower classes
Features
Enter flower measurements.
Predict flower species.
Display prediction results.
Algorithm
K-Nearest Neighbors (KNN)
Output
Predicts one of three flower species:

Setosa
Versicolor
Virginica
